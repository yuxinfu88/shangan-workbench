# 上岸工作台 🐰

国省考备考者的每日工作台，单个 HTML 文件，零依赖，可离线使用。

## 打开方式
- 手机/平板/电脑浏览器打开：`https://<你的用户名>.github.io/shangan-workbench/`
- 本地双击 `index.html` 也能用

## 数据
- 所有记录存在浏览器 localStorage（本机），关闭再打开不会丢
- 换设备：⚙️ 设置 → 导出数据包 / 导入数据包
- 侧边栏底部显示「💾 本地·未连接」或「☁️ 已连接」，一眼看出同步状态

## 功能
倒计时（毛选金句每日一换）· 每日计划（分类打卡、每日重复、逾期标红）· 政治理论（时政 5+5 条，附考点与官方原文链接）· 常识 10 条 · 言语 5 对成语辨析+检验 · 逻辑 2 题 · 数量 1 题型 · 资料 6 组公式+检验 · 每日统计 · 申论小题/大作文 · 错题本（图片、语音转文字、周汇总、导出 Word/PDF）

## 时政数据
内置数据包日期见「政治理论」页顶部；过期时页面会提示，并把新华网/中国政府网入口放在手边。
