# 上岸工作台 🐰

国省考备考者的每日工作台，单个 HTML 文件，零依赖，可离线使用。

## 打开方式
- 手机/平板/电脑浏览器打开：`https://<你的用户名>.github.io/shangan-workbench/`
- 本地双击 `index.html` 也能用

## 数据
- 所有记录存在浏览器 localStorage（本机），关闭再打开不会丢
- 换设备：⚙️ 设置 → 导出数据包 / 导入数据包（默认不含密钥）
- 侧边栏底部显示「💾 本地·未连接」或「☁️ 已连接」，一眼看出同步状态

## 数据与隐私

- 你的打卡、错题、头像、备注、统计全部存在浏览器的 localStorage，代码里没有任何上传数据的逻辑。
- 本仓库是公开的，但只有程序本体（`index.html`、`README.md`、`.nojekyll`），不含任何个人记录。
- 两个"数据出境"的出口都由你自己填：☁️ 云同步（GitHub Gist，私密 gist，token 只存本机）、周报推送（飞书 webhook）。
- 为什么用 Gist 而不是坚果云 WebDAV：坚果云不允许浏览器跨域（预检返回 401），网页端连不上；GitHub API 允许跨域。
- 导出的备份默认**不含**密码与 webhook；`.gitignore` 已挡掉 `*.json`、`*备份*`、导出物，避免误提交。
- 防泄漏三不要：不把备份 json 提交进仓库；不填公共/他人提供的 WebDAV；不把 webhook 贴到公开位置。


## 功能
倒计时（毛选金句每日一换）· 每日计划（分类打卡、每日重复、逾期标红）· 政治理论（时政 5+5 条，附考点与官方原文链接）· 常识 10 条 · 言语 5 对成语辨析+检验 · 逻辑 2 题 · 数量 1 题型 · 资料 6 组公式+检验 · 每日统计 · 申论小题/大作文 · 错题本（图片、语音转文字、周汇总、导出 Word/PDF）

## 内容性质（哪些是真的）

- **真实**：政治理论的时政条目（标题/日期/摘要抓自新华网、中国政府网，每条附原文链接）、大作文素材（真实新闻/政策，带链接）、官方金句（标注讲话/报告/文献出处）、各类公式（客观知识点）。
- **自编模拟题**：言语成语检验题、逻辑判断每日 2 题、数量关系例题、资料分析检验题、申论小题（虚构案例）、大作文分论点框架。这些按公考常见题型编写，用于练方法与手型，**不是真题原文**，解析为整理所得。
- 页面上每个题组都标了这一点，避免误当真题刷。

## 时政数据
内置数据包日期见「政治理论」页顶部；过期时页面会提示，并把新华网/中国政府网入口放在手边。
